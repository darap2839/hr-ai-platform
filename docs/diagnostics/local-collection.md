# Сбор результатов с локального Docker Desktop

Скрипт `scripts/collect-diagnostics.ps1` предназначен для Windows PowerShell 5.1
и PowerShell 7. Запускать из PowerShell на компьютере, где уже работает стенд.
Скрипт не запускает контейнеры, не загружает образы, не применяет миграции,
не создаёт записи и не изменяет конфигурацию.

Из каталога репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\collect-diagnostics.ps1
```

`Bypass` действует только в этом процессе. Постоянная политика PowerShell
не меняется. Скрипт должен лежать в `scripts` рядом с корнем проекта.
Чтобы запустить скачанную отдельно копию, явно указать каталог проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\collect-diagnostics.ps1 -ProjectDirectory "C:\Projects\hr-ai-platform"
```

Если приложение открывается по другому локальному порту, добавить
`-BaseUrl http://localhost:8080`. Для пропуска единственного синтетического
запроса Qwen добавить `-SkipAI`. Ожидание этого запроса — до 150 секунд.
Скрипт допускает только loopback-адрес приложения.

В конце выводится путь к ZIP во временном каталоге Windows. Архив содержит
`report.json` и `summary.md`. Его следует приложить в этот чат, а не в публичный PR.
Имена сотрудников, резюме, ответы модели, токены, пароли, окружение контейнеров
и исходные логи не сохраняются. Сохраняются технические идентификаторы образов,
контейнеров, статусы, версии и измеренные длительности.

SHA исходников относится к локальному checkout. Он не доказывает версию кода
в уже запущенном образе: для этого отдельно фиксируются image ID.
Показатели памяти/CPU — один снимок, не нагрузочный эксперимент.
Проверки доступности не доказывают сквозной вход, CRUD, загрузку файлов,
качество ранжирования или восстановление после отказа. Эти сценарии остаются
отдельными испытаниями этапа 1.

Workflow `Stage 1: Windows collector` проверяет синтаксис и поведение сборщика
на Windows в режимах доступного и недоступного Docker с подменами команд.
Он не выдаётся за проверку пользовательского стенда.
